# OBS Source

The plugin registers a new source named `Input Visualizer`.

## Settings

- Theme: choose `Light`, `Dark`, or `Pastel` from `themes/`
- Opacity: control overlay transparency
- Scale: control overlay size

## Placement

Use OBS transform handles to place the overlay anywhere in the scene.
