# Roadmap

## Done

- Gamepad input capture (macOS, GameController framework)
- Layered Xbox and DualSense controller art, themed at build time
- Sheet-based renderer with per-part press animation and analog triggers
- Controller auto-detection with manual override
- Keyboard and mouse overlay (opt-in)

## Near term

- Windows input backend (XInput / Raw Input); the renderer is already portable
- Per-scene profiles and a hotkey toggle
- Live theme reload without restarting OBS
- Trigger travel drawn as a fill rather than a fade

## Later

- Theme editor UI
- More controller layouts (Switch Pro, DualShock 4, generic)
- Community theme gallery
